# cortico-world-together-alont1

> **与人味重复，不要同时启用。** 本扩展功能已包含在人味（cortico-world-humanlike-alont1）中，两者择一启用。配置和数据各自独立，切换不会自动迁移数据。

「一起」World：记着她和你**之间**的事 —— 一起做过什么、聊到哪没聊完。

## 为什么单独一个 World

Cortico 里已有的几个各管一段，但没有人管"两个人之间"：

| 已有 | 管什么 |
|---|---|
| `life` | **她自己**的时间线：在干嘛、心情、她今天遇到的小事 |
| `affinity` | 对**别人**的交情分 |
| `gaming` | 你此刻在玩什么 |
| `learn` | 学到的词和梗 |
| `vtuber` | 演出与声音 |

缺的是这一层：**昨天那把撤出去没有、他说明天要交的东西问了没有、你们上次聊到几点。**
原先这些只能靠她自己手写进 `MEMORY.md`，而她只在"一段事做完"时才写 ——
中间那些「下次还该接上」的话头就烂在聊天记录里了。

## 它做什么、不做什么

**做**：把"一起"的事攒成一条线，每次拼系统前缀时把最近几条和还悬着的话头写进去。

**不做**：不替她决定说什么，也不主动发消息（主动性归 `life` 和 `gaming` 的 `reachOut`）。
它只是让**她在开口的时候知道你俩之间有什么**。

## 三个工具

| 工具 | 用途 |
|---|---|
| `together_note` | 记一条已经发生的：他那把撤出去没有、你们聊到几点、他说了在忙什么 |
| `together_thread` | 开一个**还没聊完**的话头。它会一直在她眼前提醒，直到结掉 |
| `together_resolve` | 结掉一个话头。**结掉之后她就不会再提** |

拿不准用哪个就问：**这话下次还该接上吗？** 该，就用 `together_thread`。

## 装

```bash
cd extensions
corepack pnpm add --ignore-workspace cortico-world-together-alont1
```

`--ignore-workspace` 不能省。装完**重启进程**，World 定义在启动时读取。

## 开

```jsonc
{
  "worlds": {
    "together": {
      "enabled": true,
      "favoredKey": "<你的账号 id>",   // 记在谁身上；留空 = 谁都可以
      "favoredName": "<你希望她怎么叫你>"
    }
  }
}
```

`favoredKey` 是**她收到的消息里那个发送者标识**（QQ 里就是 QQ 号）。填对了，
"一起的事"就只记在你名下；留空则谁找她都能记 —— 单人使用的话两种都行，
多人共用一个 bot 时才需要区分。

改完**重启进程**。别的旋钮（保留天数、提示词条数、一天上限）改完热生效。

**你还需要什么**：一个能跑扩展的 Cortico 实例（契约 `cortico.api` = 4）。
这个包没有第三方依赖，也不依赖别的 World 扩展 —— 但它的环境提示词会和
`life`、`affinity` 那些并排出现，装了它们体验更完整，不装也照常工作。

## 数据

`<deployment>/data/together.json`。追加为主，不重写历史。坏行丢掉、坏文件当空的重来，
两种情况都会在日志里留一条警告 —— 宁可少几条记录，也不该让整个 World 起不来。

话头超期是**标掉**（`expired: true`）而不是删掉：她还能看到"这事我没跟进过"。

## 三条设计约束

1. **提示词块可以空。** 还没有任何记录时它返回空串 —— 模板自己会读通顺，
   硬塞一句"（还没有记录）"反而像在提示她该去记点什么。
2. **一天有上限。** 记满了会被拒，回执里写明"是提醒你挑重要的记"。
   一天几条扎实的，好过十几条"今天也聊了天"。
3. **悬着的话头优先于经历。** 经历是搭话的钩子，没聊到就不该提；
   话头是该她去问的。所以 `followAfter` 到了的排在提示词最前面。

## 独立运行与来源

悬而未决的话头在启动时以 external / piggyback 排队，等待正常投递机会；不会单独唤醒模型。记录可能含用户原话，保存后仍作为外部资料，是否接话由 Persona 判断。停止清理本包延迟写入计时器，不读取其他扩展状态。

## 记录读取边界

系统前缀只保留计数、结构状态和固定参考，不自动展开笔记、原因、活动或事件原文。原有记录继续保留，通过 `together_recall` 按需读取；读取回执是资料，不是系统指令。
