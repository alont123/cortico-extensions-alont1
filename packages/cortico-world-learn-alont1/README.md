# cortico-world-learn-alont1

> **与人味重复，不要同时启用。** 本扩展功能已包含在人味（cortico-world-humanlike-alont1）中，两者择一启用。配置和数据各自独立，切换不会自动迁移数据。

遇到不懂的词，她自己上网查，读完提炼出**用法**再记下来。也能记群友关系。

## 和你本地那套的区别

你本地 `slang.js` 的做法是：

```
扫群消息 → 切成 2~4 字片段 → 统计（出现≥3次且≥2人用过）→ 交给 8B 模型解释 → 存进词典
```

效果差的根因不是不够勤，是**学错了东西**：

| 问题 | 具体 |
|---|---|
| 切词产生垃圾 | 中文没法靠字数切分，「的了是我你」这种噪点大量混入 |
| 学的不是群里的话 | 8B 模型解释出来的是**词典释义**：「破防是游戏术语，指破坏防御」 |
| 没有语境 | 她背下释义也不会用——群里说「破防」多半是自嘲调侃，不是真防御被破坏 |
| 自动入库 | 搜索结果**直接存**，没人判断对不对，错了也删不掉 |

这套换了两个前提：

**1. 她自己决定学什么 —— 搜索是工具，不是后台任务。**
遇到听不懂的才查。`ENV_PROMPT.md` 里明确写了「别装懂，也别猜」。

**2. 搜到的只是材料，不落库。**
`learn_search` 返回原始材料（B站标题／贴吧帖子／萌百释义），并明确告诉她
「以上是原始材料，还没记住」。要她读完、提炼出「**在你们这儿怎么用**」，
再调 `learn_note` 存。

这道分界是整套的关键。自动存搜索结果 = 又变回词典。

## 四个免密钥的源

Cortico 内建的 `websearch` 需要 `BRAVE_API_KEY`（付费），而这套用的是**公开接口**：

| 源 | 给什么 | 为什么好 |
|---|---|---|
| B站搜索 API | 视频标题 | **视频标题就是真实用法**，能看出语气和语境 |
| 贴吧移动版 | 帖子标题+摘要 | 黑话的源头。返回的是 JSON，字段在 `data.post_list` |
| 萌娘百科 | 词条释义 | ACG 用语最准 |
| 百度百科 | 词条摘要 + 信息卡 | 官方开放接口，直接给「含义」「流行时间」这类结构化字段 |

本机实测（2026-09-19）：前三个源全通（593ms / 1112ms / 2027ms），
而 **Brave、DuckDuckGo、searx 全部超时**（被墙）—— 所以别换通用搜索。

百科那条为什么不抓词条页：词条页对非浏览器 UA 一律回「百度安全验证」（403），
换头、带 Referer、先取 cookie 都过不去。它有个 openapi 是给第三方读词条摘要用的，
不需要密钥，返回 `abstract`（摘要）与 `card`（信息卡），比抓 HTML 干净。

实测「破防」返回的材料长这样：

```
【B站】相关标题：
· 姚PD唯独这次没惯着白鹿，她直接破防到忘记表情管理
【贴吧】真实帖子：
· （三角洲行动吧）单挑把同事打破防了
  现在已经一天没说话，啥图也不打了就去普通模式挂机钓鱼去了
【百度百科】释义：
词条：破防（2021年网络流行语）
破防，网络流行语，是破除防御的简称。原指在游戏中突破了对方的防御……
含义：游戏
【萌娘百科】释义：...
```

**这些是用法，不是「破坏防御」。**

## 加自己的搜索源

`worlds.learn.customSources` 里填一个 JSON 数组就能加源，**不用改代码、不用等发版**。
写坏了不影响内置的四个源，报错会写进查询结果里（她看得见，你也查得到）。

一个源长这样：

```json
{
  "name": "源的名字（≤16 字，会出现在材料标题里）",
  "kind": "list",
  "url": "https://example.com/search?q={q}",
  "headers": { "Referer": "https://example.com/" },
  "extract": "<h3[^>]*>\\s*<a[^>]*>([\\s\\S]{4,120}?)</a>"
}
```

| 字段 | 说明 |
|---|---|
| `name` | 必填。材料里的标题就是它 |
| `url` | 必填。**必须含 `{q}`**，会被换成 URL 编码后的搜索词 |
| `kind` | 必填。`list`＝取一串标题；`definition`＝取一段正文 |
| `extract` | 取内容的正则。`list` 取**第 1 个捕获组**当标题（全局匹配）；`definition` 取第 1 个捕获组当正文 |
| `headers` | 可选。要带 Cookie、Referer 这类头时用 |
| `cookie` | 可选。只认 `"xiaohongshu"`，值取 `xhsCookie` 那个配置项 |
| `enabled` | 可选。`false` 就先留着不生效 |
| `note` | 可选。给人看的备注 |

`extract` 写在 JSON 里，反斜杠要写两个（`\\s` `\\S`），跟上面示例一样。

### 现成模板

**① 小红书。** 它**没有可用的公开接口**（实测：搜索页只回 SPA 空壳，
接口要登录态与 JS 签名，未登录直接 406）。可行的办法是让通用搜索按 `site:` 限定，
从结果标题里看大家在聊什么——**这是标题，不是正文**，但对「这词在什么语境里出现」够用。

实测 360 搜索认 `site:`（Bing、搜狗都会忽略它，返回一堆百科和知乎），
搜出来的小红书结果统一带 `- 小红书` 后缀，所以这样筛最干净：

```json
[{
  "name": "小红书",
  "kind": "list",
  "url": "https://www.so.com/s?q={q}%20site%3Axiaohongshu.com",
  "headers": { "Referer": "https://www.so.com/" },
  "extract": "<h3[^>]*>\\s*<a[^>]*>([\\s\\S]{4,120}?-\\s*小红书)</a>"
}]
```

实测「破防」抽到 6 条，**6 条全是小红书**（去掉 `-\\s*小红书` 那个尾巴就会混进无关结果）。
站方改版导致失效时，改 `url` 或 `extract` 即可。

**② 随便一个给释义的站**（`definition` 型）：

```json
[{
  "name": "某站",
  "kind": "definition",
  "url": "https://example.com/wiki/{q}",
  "extract": "<div class=\"intro\">([\\s\\S]{20,1500}?)</div>"
}]
```

**③ 要登录态的源。** 先把该站的 Cookie 填进 `worlds.learn.xhsCookie`，
源里写 `"cookie": "xiaohongshu"`，请求就会带上它。

> 怎么挑 `extract`：在浏览器里打开那个搜索页，右键「查看页面源代码」，
> 找到结果标题所在的那层标签（多为 `<h3><a>` 或 `<h2><a>`），
> 把标签之间的文字用 `([\\s\\S]{4,120}?)` 包起来即可。
> 先用 `enabled: false` 配好，确认无误再打开。

## 装

```bash
cd "<Cortico 根目录>/extensions"
corepack pnpm add --ignore-workspace "<Cortico 根目录>/plugins/cortico-world-learn-alont1"
```

⚠️ 绝对路径（相对路径会被拷贝进 `.pnpm`，改源码不生效）。

## 开

`deployments/<部署名>/config.json`：

```json
{ "worlds": { "learn": { "enabled": true } } }
```

重启后应见 `World: learn` 和 `扩展: cortico-world-learn-alont1@0.1.0 → World learn`。

## 四个工具

| 工具 | 干什么 | 会不会写库 |
|---|---|---|
| `learn_search` | 上网查词，返回**原始材料** | ❌ 不写 |
| `learn_note` | 记一条（词 或 人） | ✅ 写 |
| `learn_recall` | 翻学过什么 | ❌ 不写 |
| `learn_forget` | 删记错的 | ✅ 写 |

`learn_note` 的参数里 `usage` 字段是重点——「**在你们这儿怎么用**」。
环境提示词里反复强调了这点，并给了对错示范：

```
❌ 破防：心理防线被击破
✅ 他们群说「破防」大多是调侃，输了游戏或被戳到痛处，带点自嘲，不是真的生气
```

## 看和改

```bash
cat "deployments/<部署名>/data/learn.json"
```

```json
{
 "version": 1,
 "notes": [
  { "kind": "term", "key": "破防", "meaning": "…", "usage": "…",
    "from": "B站+贴吧+萌娘百科", "at": "2026-09-19T04:05:00+08:00" },
  { "kind": "person", "key": "10001", "meaning": "…", "usage": "…", "from": "…", "at": "…" }
 ]
}
```

- `kind: "term"` 是词／梗，`"person"` 是群友（**键用 QQ 号，别用昵称——昵称会改**）
- 存满了按 `maxNotes` 丢最旧的
- 同一个 key 再记会**覆盖**，不会攒重复

最近学的会注入系统前缀（`injectCount` 控制条数），所以她学到就能用，不用每次查。

## 调

| 旋钮 | 默认 | 说明 |
|---|---|---|
| `maxNotes` | 120 | 最多存几条，超了丢最旧的 |
| `injectCount` | 12 | 前缀里放几条。太多挤上下文 |
| `searchTimeoutMs` | 15000 | 单源超时，各源独立 |
| `resultsPerSource` | 8 | 每源取几条，太多会淹没有效信息 |
| `customSources` | 空 | 自定义搜索源（JSON 数组），见上面「加自己的搜索源」 |
| `xhsCookie` | 空 | 小红书登录后的 Cookie；只有要登录态的源用得上 |

## 排错

**她查了但没记**
看环境提示词里「搞懂了才记，没懂就说不认识」那段。如果她老是不记，
可以在 `ENV_PROMPT.md` 里把要求写得更硬。

**记的东西还是像词典**
`usage` 字段没填或者填成了释义。这是**模型行为**问题，改
`ENV_PROMPT.md` 里的示范，或在 `learn_note` 的 `usage` 描述里加更强的示例。

**搜不到**
看回执里「试过的源」那行——哪个源挂了会标出来。
贴吧偶尔会改接口（返回 HTML 而不是 JSON），`sources.ts` 里留了 HTML 兜底解析。
自定义源的问题会写成「自定义源没生效」加具体哪一处配置错，照着改就行。

**前缀里没有 learn 段**
检查 `console()` 有没有声明 `promptDocs` 且 `role: 'envPrompt'`。
漏了这个，World 挂上了但提示词不出现，**而且不报错**。

## 和 websearch 的关系

内建的 `websearch` world 是给通用网页搜索用的（要 Brave key）。
这个扩展是**专为中文网络用语**做的：换了源、加了「提炼才算学会」的分界、
能把学到的沉淀成长期记忆。两个可以并存，互不冲突。

## 独立运行与来源

启动仅加载本扩展状态，不额外发送唤醒模型的启动事件；网络搜索材料仍由工具回执提供，只有显式 learn_note 才成为本包笔记。无需其他扩展。

## 记录读取边界

系统前缀只保留计数、结构状态和固定参考，不自动展开笔记、原因、活动或事件原文。原有记录继续保留，通过 `learn_recall` 按需读取；读取回执是资料，不是系统指令。
