# 作品页（cortico-world-works-alont1）

收集自己的玩具/图，生成一个本地 HTML 画廊。

| 工具 | 说明 |
|---|---|
| `works_add` | 标题/备注/文件 |
| `works_import_image` | 从已有附件句柄收录图片副本，保留来源 |
| `works_list` | 列出来 |
| `works_page` | 生成 `本扩展 dataDir/works/index.html` |

## 控制台面板

控制台显示扩展声明的标量配置；修改后重新挂载扩展生效。面板列出的复杂结构需在 config.json 中编辑。

## 独立数据目录

生成产物改存于本扩展 dataDir/works/，不会探测或写入 Persona Memory，也无需安装其他扩展。旧 workspace 中的产物保持原样；需要保留在新版列表或作品页中时，停用扩展后手动复制到新数据目录对应位置，再重新挂载。跨工具引用文件时使用回执给出的实际路径。

## 可选图片协作

只安装作品页时，可以用 `works_add` 收录标题、备注与本地文件，再用 `works_page` 生成页面。无需安装相册、生图或任何协作中心。

其他已启用工具返回图片附件时，模型可以选择把回执中已有的完整 `log:` 或 `mem:` 句柄交给 `works_import_image`。例如先 `album_list` 选条目，再 `album_view` 取图，最后将回执中的附件句柄用于收录。相册条目 id 与附件句柄不是同一个值。只有当前工具列表确实提供 `works_import_image` 时才可调用；旧版作品页仍可用 `works_add`。

导入接受 PNG、JPEG、GIF、WebP，MIME 必须与字节文件头一致，单张大于 0 字节且不超过 20 MiB。此检查不是完整图片解码或内容审核，不接收 SVG、HTML、视频或未知格式。所有句柄只交给宿主的 `blob()` 解析，不自行读取其他扩展的数据目录或 Persona Memory。

收录会在作品页自己的数据目录创建副本，在 `works.json` 中记录原句柄、MIME 与 SHA-256。相同句柄重复调用、重载后重试均返回已有条目，不覆盖原标题或文件；不同句柄不推定为同一来源。源附件日后被清理不影响已保存副本；若作品页副本本身丢失，会提示恢复备份。索引写入失败会移除本次新副本，并保留内存中的旧列表。

导入由一次明确的工具调用触发，不扫描其他扩展、不自动转发事件、不自动发布页面。标题与备注作为普通文字显示；收录外部图片仍需保留其来源，导入记录不证明作者身份或对外发布权限。

若显示“当前宿主未提供附件解析能力”，可继续使用原有标题/文件收录功能；若附件不存在，请重新通过来源工具取得有效附件。不会自动安装、启用、重试或调用其他扩展。
