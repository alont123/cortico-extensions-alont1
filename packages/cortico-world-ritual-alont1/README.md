# 仪式感

根据部署时区提供早间、晚间和自行登记的纪念日提醒，不依赖其他扩展。

## 中文使用教程

控制台设置 morningAt / nightAt（HH:MM），保存后重新挂载。ritual_set({date,name}) 登记纪念日，ritual_list 查看。日期会统一为 MM-DD，并检查日期真实有效，允许 02-29；名称 1—200 字。

早间、晚间、纪念日使用各自去重标记；同一分钟同时到点不会互相覆盖。提醒均使用 piggyback，不单独唤醒模型。固定的早晚时间通知为 internal；纪念日名称来自登记文本，按 external 外部资料投递，落盘不会把原文变成内部指令。事件确认入库后保存去重状态，投递失败可重试；在入库成功但状态尚未落盘时异常退出，下一次启动仍可能重投。

状态位于部署数据目录 ritual.json，以临时文件改名写入。旧 lastMorning 中的周年标记迁移到独立 lastAnniversary，不删除原纪念日。不同部署不共享列表。World 只报告已到配置的时间，不声称现实已经天亮或变晚。
