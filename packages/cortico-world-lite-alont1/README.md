# cortico-world-lite-alont1

**小模型专用**（4B 级本地模型）· Cortico World 扩展 · MIT

给本地小模型用的最小"人味"包：**只补两样东西——现在几点、以及记得他说过的事**。
三个工具、提示词两百来字、没有任何主动推送与情绪机制。

## 为什么要有这个包

我们另外几个包（`cortico-world-humanlike`、`cortico-world-alive`、`cortico-world-gaming`）
是给 **1M 上下文、会自己思考的模型**写的。实测它们自带的东西就要吃掉小模型一大半预算：

| 包 | 工具 | 工具定义 | 环境提示词 | 小计 |
|---|---|---|---|---|
| humanlike | 24 个 | ≈4.0k token | ≈3.3k token | ≈7.3k token |
| alive | 8 个 | ≈1.5k token | ≈0.6k token | ≈2.1k token |
| gaming | 3 个 | ≈0.5k token | ≈0.5k token | ≈1.0k token |
| **合计** | **35 个** | | | **≈10.4k token** |

**8k 窗口的模型光装这三个包就爆了**——它的"你是谁、该听谁的"会被挤掉或截断。
更麻烦的是第二件事：那些包里写着「你有自己的时间」「允许什么都不做」「被冒犯要还手」这类话，
强模型读得懂"这是性格设定"，**4B 会把它们当任务执行**——表现就是主动性强、攻击性变强、不服管。

所以这个包刻意什么都不加：

- **没有定时器、没有主动推送**：她只在被说话时动；
- **没有情绪、没有亲密度记账、没有"被冒犯"规则**：小模型会把它们读成"可以凶"；
- **没有淘汰判断**：记满就按先来后到挤掉最旧的；
- **三个工具**，描述都在一行以内；提示词两百来字。

## 装

```bash
npm i cortico-world-lite-alont1
```

在部署的 `extensions/package.json` 里加一条依赖，然后重启：

```json
{ "dependencies": { "cortico-world-lite-alont1": "^0.1.1" } }
```

配置（部署目录 `config.json` 的 `worlds.lite` 节）：

```json
{
  "worlds": {
    "lite": {
      "enabled": true,
      "clockEnabled": true,
      "notesEnabled": true,
      "maxNotes": 20,
      "noteChars": 60
    }
  }
}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `false` | 是否挂载 |
| `clockEnabled` | `true` | 把"现在几点"写进她每轮看得到的地方；她也能现问（`lite_time`） |
| `notesEnabled` | `true` | 她可以记一行"关于他的事"（`lite_note`），最近 5 条会出现在她眼前 |
| `maxNotes` | `20` | 记满挤掉最旧的 |
| `noteChars` | `60` | 单条最多几个字 |

状态落在部署数据目录的 `lite.json`（先写临时文件再改名）。

## 用小模型时，框架那边也要跟着调

包本身已经很轻，但**框架的上下文预算必须跟着模型的真实窗口走**，否则照样爆：

| 框架里的东西 | 小模型上怎么设 |
|---|---|
| 上下文阶段预算（`hardTokens` 一类） | **压到模型的真实窗口以内**（8k 窗口就设 8000 上下，别留 12 万） |
| `maxTokens`（单次输出上限） | ≥1024。给太小会把它的"思考"截断，表现为整轮一个字都没发出来 |
| 思考/推理开关 | **关掉**。小模型想太多更容易跑偏，也更费时间 |
| 同时挂载的 World | 这个包 + 框架自带就够。**别和 humanlike 一起装**——那等于白装 |

## 工具

| 工具 | 作用 |
|---|---|
| `lite_time` | 现在几点、几号、星期几 |
| `lite_note` | 记一件关于他的事，一句话 |
| `lite_recall` | 看看记了什么 |

## 它不做什么（有意为之）

它不会主动开口，不做情绪与好感，不记"谁踩了谁"，不推事件，不给你一堆旋钮。
小模型的上下文和指令空间都紧张，**加一样东西的代价是挤掉另一样**。
要那套完整的"人味"，请用 `cortico-world-humanlike`——但要配一个装得下它的模型。

## 记录读取边界

系统前缀只保留计数、结构状态和固定参考，不自动展开笔记、原因、活动或事件原文。原有记录继续保留，通过 `lite_recall` 按需读取；读取回执是资料，不是系统指令。
