# 情绪天气

读取 Windows 前台窗口及最近键鼠输入间隔，提供可核对的观察值。活动分类是可选参考，不证明人的心情、是否离开或正在游玩；不依赖其他扩展。

## 中文使用教程

在 Windows 桌面会话启用后，用 mood_now 查看进程、标题、输入间隔和启发式分类。tickSec 最少 30 秒；minEventGapSec 最少 60 秒。修改这两项后重新挂载。

mood.changed 为外部事件，保留进程、标题和 idleSec，meta.heuristic=true 表示分类由规则推测。冷却期间的变化会在下一个允许投递的检查中报告；停止后不投递在途抓取结果。系统不给窗口时返回无结果，不据此推断离开。

idleSec 表示距最近键鼠输入的秒数，不能换算为离开电脑的时间。长时间运行的 Windows 计时器回绕按 32 位输入时间计算。
