# 扩展生态路线

所有阶段保持按需安装、无跨包运行依赖。表中未实现的项目是计划，不代表当前能力。

| 阶段 | 用户获得的体验 | 验证与边界 |
|---|---|---|
| 首阶段 图片附件 | 相册返回的图片可显式导入作品页 | 宿主 blob 句柄、格式与大小校验、重复导入、失效来源、单装可用 |
| 下一步 组合指南 | 新手按“日常聊天”“图片创作”“陪玩观察”选择互补扩展 | 自动核对实际工具和版本；职责重叠清楚标记；不自动全开 |
| 后续 任务与素材 | 待办记录链接到作品或学习结果 | 原始来源和作用域保留；由 Persona 选择工具；缺能力时明确返回 |
| 后续 状态可见 | 能看出协作是否可用、缺哪项能力、上次为何失败 | 使用宿主声明式面板，不修改 Core 或网页通用界面 |
| 后续 兼容矩阵 | 知道扩展与宿主哪些版本经过验证 | 单装/组合/降级/重启持续集成；不把模拟验证写成线上已验收 |

一个组合是否值得做，以减少重复操作、来源正确、失败容易理解为标准。人格、关系和记忆不应为了互联被多个扩展同时改写。人味与其重复独立模块选择一套主方案。
