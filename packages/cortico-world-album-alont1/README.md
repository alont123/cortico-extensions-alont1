# cortico-world-album-alont1

把收到过与发出去的图存成一份**能翻的册子**：按人、按时间、按会话都找得回来，看过还能自己写一句这是什么。

## 为什么要有它

在此之前，她"看见"一张图的能力只有一次性的：别人发来的那张当时能看，过后就只剩记忆里一句话。
于是会出现这种事——

- 主人说"上次给你看的那张"，她只能含糊应付，因为那张图她翻不回去了；
- 她自己发出去过的图，也认不出来是自己发的第几张；
- 想让另一张图当参考，得等人再发一遍。

而这些图的字节**一直都在**（事件库里的 `log:` 句柄、她工作区 `blobs/` 下的 `mem:` 句柄），
缺的只是**一份能按条件翻回来的索引**。这个扩展就干这一件事。

## 它怎么工作

不做复制、不搬字节。启动时从事件库捡一遍：

```
事件（EventEnvelope）带的附件
  → 记下句柄 + 谁发的 + 哪个会话 + 什么时候 + 当时的说明
  → 写进 <dataDir>/album.json
```

看的时候才把句柄交给宿主解析出字节（`log:` 与 `mem:` 都认），
按框架的附件通道递给她——**跟别人刚发来一张图时她"看见"的方式完全一样**。

- **只增不扫重**：记下扫到哪条游标，下次接着走。启动时补一次增量。
- **句柄失效也不崩**：字节被清理过的那种，报"字节已经不在了"，其余照常。
- **库很大也不怕**：分段读（`scanChunk`），只挑带图的事件。

## 四个工具

| 工具 | 干什么 | 会不会写 |
|---|---|---|
| `album_list` | 翻：按人／按会话／按时间段筛，列出可看的 id | ❌ |
| `album_view` | 真的翻开某几张（把图递给她看） | ❌ |
| `album_note` | 给自己写标题与备注 | ✅ |
| `album_scan` | 手动补扫／列出出现过哪些人 | ❌ |

**先 list 再 view** 是刻意的：让她先想清楚要看哪几张，而不是把册子整个倒进上下文。
`maxViewsPerCall` 就是这条的闸。

`album_note` 写的是**她自己认图的线索**——"他拿去当头像那张"比"一只猫"有用得多。

## 装

```bash
cd "<Cortico 根目录>/extensions"
corepack pnpm add --ignore-workspace "<Cortico 根目录>/plugins/cortico-world-album-alont1"
```

⚠️ 绝对路径（相对路径会被拷进 `.pnpm`，改源码不生效）。

## 开

`deployments/<部署名>/config.json`：

```json
{ "worlds": { "album": { "enabled": true } } }
```

重启后应见 `World: album`。

## 调

| 旋钮 | 默认 | 说明 |
|---|---|---|
| `maxViewsPerCall` | 4 | 一次最多翻开几张。翻太多挤上下文、也让那轮请求变贵 |
| `listLimit` | 30 | 一次列几条。只影响列出来的行数 |
| `scanChunk` | 2000 | 补扫时一次读多少条事件 |

## 排错

**册子里是空的**
先 `album_scan` 带 `all: true` 扫一遍。还是空就说明事件库里本来就带图的事件很少——
她收到的图有没有落成附件，取决于 QQ 那个 World 有没有把图当 blob 推。

**"字节已经不在了"**
那条记录的句柄指向的字节被清理过（比如她清过工作区）。
记录本身留着，能看到"当时有这么一张、谁发的"，只是看不了了。

**找不到某张图**
`album_list` 支持按 `person` 筛，但人名是从事件里读的，可能有的记录只有账号没有名字。
先用 `album_scan` 带 `people: true` 看册子里到底记了哪些人。

## 独立运行与来源

系统前缀仅包含图片数量。条目 ID 可能带原始附件文件名，因此和昵称、附件说明一起在 album_list / album_view 回执中提供，属于外部材料。只有生产方明确标记 direction=outgoing 或 sentByBot=true 的事件被识别为 bot 发出；仅有 World 名称的来源不能证明发送行为。

## 旧版漏扫修复

旧版在事件超过一页时可能把扫描游标直接推进到末尾。升级后调用一次 `album_scan`，参数为 `{ "all": true }`，即可补扫历史图片；已有备注保留，原图片文件不移动。之后按游标正常增量扫描。
