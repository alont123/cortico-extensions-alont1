# 截图日记（cortico-world-diary）

截一张当前屏幕存进当天日记，可以附一句。**Windows 专用、默认关闭**（隐私开关）。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `worlds.diary.enabled` | `false` | 开关 |
| `worlds.diary.outDir` | `data/diary` | 存放目录 |
| `worlds.diary.maxPerDay` | `5` | 每天最多几张 |

## 工具

- `diary_snap({note?})`：截主屏 → `<outDir>/<YYYY-MM-DD>/NN.png` + `.json`（时间/句子）。
- `diary_today()`：今天写了什么。
- `diary_list({days?})`：最近几天各有几张。

## 注意

只截主屏、只在工具被调用时截；不主动定时、不上传。截图里可能有私人内容，开之前想清楚。

## 控制台面板

控制台显示扩展声明的标量配置；修改后重新挂载扩展生效。面板列出的复杂结构需在 config.json 中编辑。

## 本次可靠性更新

同一实例一次只执行一张截图，避免并发穿过每日上限。编号取现有图片的最大编号加一，删除中间图片后不会覆盖后面的图片。系统没有生成非空图片时明确返回失败；本次回归使用模拟截图函数，没有读取真实屏幕。
